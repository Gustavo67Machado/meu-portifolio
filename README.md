# Protótipo de Portfólio Profissional

## Sobre o projeto

Este projeto apresenta um protótipo de portfólio profissional desenvolvido para organizar e apresentar minhas informações acadêmicas, habilidades e projetos na área de tecnologia.

O portfólio foi criado no **Figma**, com apoio do **ChatGPT** para planejamento, organização das informações e desenvolvimento do conteúdo.

## Ferramentas utilizadas

- **Figma** — criação do protótipo e layout das telas.
- **ChatGPT** — apoio na organização do conteúdo, ideias para o layout e desenvolvimento do projeto.
- **GitHub** — armazenamento e apresentação do projeto.
